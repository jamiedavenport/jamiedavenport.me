## Start with a useful example

Fenced code blocks use syntax highlighting at build time. Add a language after the opening fence, such as `ts`, `bash`, `json`, or `diff`.

```ts
type Article = {
  title: string;
  publishedAt: Date;
  draft?: boolean;
};

function publishedArticles(articles: Article[]) {
  return articles
    .filter((article) => !article.draft)
    .toSorted((a, b) => b.publishedAt.getTime() - a.publishedAt.getTime());
}
```

Long lines scroll within the code block, leaving the rest of the page in place.

```bash
curl --request GET --header 'Accept: application/json' 'https://example.com/api/articles?sort=publishedAt&direction=descending&include=description'
```

### Explain the tradeoff

Use paragraphs, **emphasis**, and links to [supporting documentation](https://docs.astro.build/en/guides/content-collections/) to explain the code.

## Compare the options

| Feature    | How to write it                            | Result                                 |
| ---------- | ------------------------------------------ | -------------------------------------- |
| Code       | A fenced block with a language             | Highlighted at build time              |
| Screenshot | An imported image and Screenshot component | Responsive image with optional caption |
| Table      | A Markdown table                           | Scrolls horizontally when necessary    |

### Before publishing

- Choose a stable, lowercase, hyphenated folder name and put the article in `index.mdx`.
- Write a specific title and description.
- Set the publication date and remove `draft: true`.
- Run the checks documented in the README.
